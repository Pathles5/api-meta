Sobre IG-API

Descripción: API REST para integrar con la API de Instagram Graph de Meta, diseñada para recuperar publicaciones y manejar eventos de webhooks.

Propósito: Proyecto educativo para aprender desarrollo asistido por IA y integración con APIs de redes sociales.

Stack: Node.js, Express.js, DynamoDB, AWS CDK

Repositorio: github.com/Pathles5/api-meta
