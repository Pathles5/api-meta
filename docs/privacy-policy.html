IG-API

Instagram Graph API Integration

Política de Privacidad

Última actualización: 7 de junio de 2026

1. Introducción

Esta Política de Privacidad describe cómo IG-API ("nosotros", "nuestro") recopila, usa y protege la información cuando utiliza nuestro servicio de integración con la API de Instagram Graph de Meta.

2. Datos que Recopilamos

Recopilamos únicamente los datos necesarios para el funcionamiento del servicio:

  • Datos de Instagram: Publicaciones (posts), comentarios, menciones y metadatos asociados (fechas, likes, conteo de comentarios)
  • Datos de uso: Información sobre cómo se utiliza la API (endpoints consultados, horarios de acceso)
  • Datos de autenticación: Tokens de acceso de Meta API y claves de API para autenticación

3. Cómo Usamos los Datos

Utilizamos los datos recopilados para:

  • Almacenamiento: Guardar publicaciones de Instagram en DynamoDB para acceso rápido
  • Análisis: Proporcionar estadísticas básicas sobre publicaciones (likes, comentarios)
  • Sincronización: Mantener los datos actualizados con la API de Instagram
  • Verificación: Validar que las publicaciones sigan existiendo en Instagram

4. Protección de Datos

Medidas de seguridad implementadas:

  • Cifrado en tránsito: Todas las comunicaciones se realizan mediante HTTPS/TLS
  • Cifrado en reposo: Los datos en DynamoDB se cifran automáticamente con claves de AWS
  • Autenticación: API keys para controlar acceso a los endpoints
  • Rate limiting: Protección contra abuso y sobrecarga
  • Aislamiento: Cada entorno (pre, int, pro) tiene sus propios recursos aislados

5. Retención de Datos

Los datos se almacenan temporalmente:

  • TTL (Time-To-Live): 90 días por defecto
  • Eliminación automática: Los datos se eliminan automáticamente después del período de retención
  • Eliminación bajo demanda: Puede solicitar la eliminación de sus datos en cualquier momento

6. Derechos del Usuario

Usted tiene derecho a:

  • Acceso: Solicitar una copia de todos los datos que tenemos sobre usted
  • Rectificación: Solicitar corrección de datos inexactos
  • Eliminación: Solicitar la eliminación de todos sus datos
  • Portabilidad: Recibir sus datos en un formato estructurado
  • Oposición: Oponerse al procesamiento de sus datos

7. Compartición de Datos

No compartimos sus datos con terceros, excepto:

  • Meta (Facebook): Únicamente para obtener datos de Instagram mediante la API oficial
  • AWS: Como proveedor de infraestructura (DynamoDB, Lambda, API Gateway)
  • Requisitos legales: Cuando sea requerido por ley

8. Cambios en esta Política

Podemos actualizar esta política periodicamente. Los cambios significativos se notificarán mediante actualización de la fecha de "Última actualización" en la parte superior de esta página.
